# uno-frontend

Interfaz en React (Vite + CSS Modules) para el juego Uno.

## Uso

```bash
npm install
npm run dev
```

Abre la URL que muestre la terminal (por defecto http://localhost:5173).

## Estructura

- `src/components/MainMenu/` — menú principal (título screen).
- `src/index.css` — tokens de diseño globales (colores, tipografías).
- `src/App.jsx` — punto donde se irán agregando/cambiando pantallas.
